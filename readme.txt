WordPress投稿の更新日（post_modified）をロックし、SEO最適化のために更新日を意図的にコントロールできます。

== Description ==

このプラグインは、WordPressの投稿・固定ページ・カスタム投稿タイプの更新日を管理し、編集時に自動的に更新されないようにロックする機能を提供します。SEO対策として、更新日を意図的にコントロールしたい場合に便利です。

SEO対策研究室（https://www.tsuyoshikashiwazaki.jp）で開発されたプラグインです。

= 主な機能 =

* **更新日ロック機能**
    * デフォルトでロック状態: 投稿を作成すると、自動的に更新日がロックされます（ロックは公開後に有効）
    * チェックボックスで簡単切り替え: 切り替えた時点で保存されます。チェックを外すと、保存するたびに更新日が保存時刻になります
    * 投稿タイプの選択: どの投稿タイプにロック機能を適用するか選択可能

* **手動更新日変更機能**
    * 「更新日を変更」ボタンでその場で反映（投稿の保存は不要）。変更するとロックが自動で ON になります
    * 日時入力フォーム: 未来の日時は指定できません。公開日より前の日時は公開日時に合わせます
    * 「公開日と同じにする」ボタン: 公開日時（秒まで）を指定できます

* **日付の不整合の確認・修復**
    * 更新日が公開日より前の投稿、GMT の更新日が記録されていない投稿を設定画面で確認・修復できます

* **視覚的な情報表示**
    * 現在の更新日時: 年月日・時刻を日本語形式で表示
    * 経過時間: 「3日前」「2ヶ月前」などの分かりやすい表示

= 使用例 =

* SEO対策として、更新日を固定したい場合
* 軽微な修正で更新日を変えたくない場合
* 過去記事の更新日を意図的にコントロールしたい場合
* リライト時に更新日を任意の日時に設定したい場合

== Installation ==

1. プラグインフォルダを `/wp-content/plugins/` ディレクトリにアップロード
2. WordPress管理画面の「プラグイン」メニューからプラグインを有効化
3. 管理画面メニューの「Kashiwazaki SEO Lock Modified Date」から設定を行う

または

1. WordPress管理画面の「プラグイン」→「新規追加」を開く
2. 「Kashiwazaki SEO Lock Modified Date」で検索
3. 「今すぐインストール」をクリック
4. 「有効化」をクリック

== Frequently Asked Questions ==

= 既存の投稿にもロック機能を適用できますか？ =

はい。ロック状態が記録されていない既存の投稿は、設定「デフォルトでロックする」に従います。編集画面の「更新日をロックする」で個別に切り替えることもできます。

= ロック状態でも更新日を変更できますか？ =

はい、「更新日を手動で変更」で日時を選び「更新日を変更」を押すと、その場で変更されます。

= カスタム投稿タイプにも対応していますか？ =

はい、すべての公開カスタム投稿タイプに対応しています。設定画面で選択できます。

= プラグインを無効化するとどうなりますか？ =

プラグインを無効化すると、通常通り更新日が自動更新されるようになります。メタデータは削除されませんので、再度有効化すると以前の設定が復元されます。

= デフォルトの動作は？ =

デフォルトでは、新規投稿作成時に自動的にロック状態（チェックON）になります。公開済みの投稿は、編集・保存しても更新日は変わりません（未公開の間はロックが効かず、公開後に有効になります）。

= 更新日のロックを解除するには？ =

投稿編集画面のサイドバーにある「Kashiwazaki SEO Lock Modified Date」メタボックスで、「更新日をロックする」のチェックを外してください。

== Technical Specifications ==

= フック =
* `wp_insert_post_data` / `wp_insert_attachment_data`: 投稿保存時に更新日をロック
* `add_meta_boxes`: メタボックスの追加
* `wp_insert_post` / `add_attachment`: 新規作成時のロック状態の記録
* `transition_post_status`: 予約投稿の自動公開時の更新日の補正（ロック中の投稿のみ）
* `wp_ajax_kseo_set_lock`: AJAX処理（ロックの切り替え）
* `wp_ajax_kseo_update_modified_date`: AJAX処理（手動更新日変更）
* `wp_ajax_kseo_get_modified_state`: AJAX処理（表示の同期）
* `wp_ajax_kseo_repair_dates`: AJAX処理（日付の不整合の修復）
* 更新日の手動変更と修復では、更新日の 2 列だけを書き換えたあと、投稿の更新と同じ順序で `pre_post_update` / `transition_post_status` / `edit_post` / `post_updated` / `save_post` / `wp_insert_post` / `wp_after_insert_post`（メディアは `edit_attachment` / `attachment_updated`）を発火します。REST API 固有のフックとタームのフックは発火しません

= メタデータ =
* `_kseo_lock_modified_date`: ロック状態を保存（0 or 1）

= オプション =
* `kseo_lock_modified_date_post_types`: ロック機能を使う投稿タイプの配列
* `kseo_lock_modified_date_default_locked`: デフォルトでロックするか（1 / 0）

= セキュリティ =
* nonceによるCSRF対策
* 権限チェック（current_user_can）
* データのサニタイズとエスケープ
